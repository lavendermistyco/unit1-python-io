# Unit 1: Environment Provisioning & Basic I/O

Welcome to **7th Grade Computer Science: Cloud-Native AI Engineering & System Architecture**. In this unit, we transition from visual blocks to text-based Python software development executed entirely inside cloud-provisioned Linux containers.

---

## 🚀 Quickstart: Launching Your Workspace

1. Click the green **`<> Code`** button at the top right of this repository.
2. Select the **Codespaces** tab.
3. Click **Create codespace on main**.
4. Wait ~60 seconds for your browser tab to initialize your Linux cloud container.
